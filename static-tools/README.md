# Tools Hub

A curated collection of 7 essential utility tools with an editorial/magazine design aesthetic and Neo-Brutalism touches. Free to use, no signup required.

## 🛠️ Tools Included

1. **📝 Text Utils** - Word/character counter, case converter
2. **🔐 Password Generator** - Custom length, character options
3. **💪 BMI Calculator** - Height/weight to BMI with category display
4. **🎮 FF Nickname Generator** - Gaming names with styles (Cool, Gaming, Stylish, Aggressive)
5. **🖼️ Meme Generator** - Classic meme creation with top/bottom text
6. **🎯 Quiz App** - General knowledge questions (5 questions)
7. **📊 Image Compressor** - Client-side image compression

## ✨ Features

- **Dark Mode** - System preference detection + manual toggle with localStorage persistence
- **Responsive Design** - Mobile-first approach, works on all devices
- **No Backend** - All processing happens in your browser
- **Privacy First** - Your data never leaves your device
- **Neo-Brutalist Design** - Hard offset shadows, visible borders, bold typography
- **Google AdSense** - Ad placeholders ready for monetization

## 🎨 Design System

- **Typography:** Playfair Display (headings), Lora (body), Inter (labels)
- **Colors:** Warm off-white background, charcoal text, steel blue accent
- **Neo-Brutalism:** Hard offset shadows (5px/8px), visible borders, bold elements

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in any web browser
3. No build process or dependencies required!

```bash
git clone https://github.com/yourusername/tools-hub.git
cd tools-hub
# Open index.html in browser
```

## 📱 Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## 🔒 Privacy

All tools process data locally in your browser:
- Text is never transmitted
- Images are processed using Canvas API
- Passwords are generated client-side only

## 💰 Monetization

The project includes AdSense placeholders ready for monetization:
- Header: 728x90 leaderboard
- Between tools: 300x250 rectangle
- Footer: Responsive ad unit
